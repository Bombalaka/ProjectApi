# Simple API Project

This is a small project I created to learn how to build an API from scratch using C#. The goal of this project was to understand the basics of API development, including how to:

- Set up an API structure
- Create endpoints for different operations (CRUD)
- Store and manage data using a database

## 💡 Features

- Basic REST API (GET, POST, PUT, DELETE)
- Entity creation and storage in a database
- Clean and simple project structure for beginners
- Written in C# with .NET

## 🛠️ Technologies Used

- C# / .NET
- ASP.NET Core Web API
- Entity Framework Core (optional, if used)
- SQLite / MongoDB / (mention your database)
